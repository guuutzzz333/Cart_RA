Why a proxy?
RetroAchievements' API doesn't reliably send the browser permission headers (CORS) that let a website call it directly. If your data won't load, deploy the tiny proxy-worker.js file included alongside this app to Cloudflare Workers (free tier), then paste its URL above. Everything still uses your own key — the proxy only forwards requests.
